The ones people ask before connecting it.

What is MCP?

The Model Context Protocol is the standard way an AI coding agent connects to an outside tool. You add a server to your agent's config once, and its tools become available in every conversation you have in that client.

Which clients does it work with?

Any client that speaks MCP: Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Zed, and agent frameworks with an MCP client. The config block is the same everywhere.

Does anything about my project get sent anywhere?

No. Your agent sends ThinkUI a design question and gets an answer from ThinkUI's own reference library. Your code, files and repository are never sent, and the server cannot reach them.

What happens when it does not know something?

find_ui_elements returns no component and lists the categories that do exist. find_ui_references returns its nearest match and shows why it matched, so a weak hit is visible as a weak hit instead of passing for an answer.

Can I use what it returns in commercial work?

Components, icons and materials are MIT and yours to ship. Screenshots are mixed: 417 of 1,483 are permissively licensed and the rest are study-only, marked do not ship in the result that returns them. Every result names its source and its licence, so you can tell which is which before you use it.

How do I cancel?

From the billing portal in your account. Cancelling stops the next charge and your key keeps working until the end of the period you paid for. Partial periods are not refunded; if the server returns nothing useful in your first week, write to us and we refund that month.
